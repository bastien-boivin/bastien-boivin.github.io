## Contexte

Hyprland est un compositeur Wayland tiling avec des animations fluides intégrées. Contrairement a Sway, les animations, le blur et les coins arrondis font partie du moteur de rendu, ce qui donne un rendu visuel bien au dessus sans plugins externes.

> [!warning] Support officiel
> Hyprland ne supporte officiellement que Arch et NixOS. Sur Fedora, le fonctionnement repose sur des depots COPR maintenus par la communaute. Ca marche bien en pratique, mais il n'y a pas de support officiel en cas de bug.

Configuration realisee sur un laptop avec ecran 1920x1200 et un moniteur Dell U3417W ultrawide 3440x1440.

## Installation

### Activer le depot COPR

Le depot recommande par le wiki officiel Hyprland pour Fedora est `lionheartp/Hyprland` :

```bash
# Activer le depot COPR
sudo dnf copr enable lionheartp/Hyprland

# Installer Hyprland et le portail XDG (screen sharing)
sudo dnf install hyprland xdg-desktop-portal-hyprland
```

### Installer les outils essentiels

```bash
# Terminal
sudo dnf copr enable pgdev/ghostty
sudo dnf install ghostty

# Barre, lanceur, notifications, fond d'ecran
sudo dnf install waybar wofi mako hyprpaper

# Screenshots et clipboard
sudo dnf install grim slurp wl-clipboard cliphist

# Verrouillage d'ecran
sudo dnf install hyprlock

# Controle volume et luminosite
sudo dnf install brightnessctl playerctl
```

### Installer une Nerd Font

Les icones de waybar necessitent une police Nerd Font. Sans elle, les icones s'affichent comme des caracteres illegibles.

```bash
mkdir -p ~/.local/share/fonts
cd /tmp
curl -fLO https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.tar.xz
tar -xf JetBrainsMono.tar.xz -C ~/.local/share/fonts/
fc-cache -fv
```

## Configuration de Hyprland

Le fichier de configuration principal est `~/.config/hypr/hyprland.conf`. Au premier lancement, Hyprland genere une config par defaut avec un message jaune d'avertissement. Supprimer la ligne `autogenerated = 1` pour le retirer.

### Moniteurs

La disposition des moniteurs se configure avec la directive `monitor`. Le format est :

```
monitor = NOM, RESOLUTION@REFRESH, POSITION, SCALE
```

Pour connaitre le nom de ses ecrans :

```bash
hyprctl monitors
```

Exemple avec un ultrawide en haut et un laptop centre en dessous :

```ini
# Ultrawide en haut
monitor = DP-5, 3440x1440@60, 0x0, 1

# Laptop centre en dessous
# Position X = (3440 - 1920/1.25) / 2 = 952
monitor = eDP-1, 1920x1200@60, 952x1440, 1.25

# Fallback pour les ecrans non configures
monitor = , preferred, auto, auto
```

> [!info] Calcul du centrage
> La position X du laptop depend de son scale. A scale 1.25, la largeur effective est 1920/1.25 = 1536px. Pour centrer sous un ecran de 3440px : (3440 - 1536) / 2 = 952.

### Programmes par defaut

```ini
$terminal = ghostty
$fileManager = nautilus
$menu = wofi --show drun
$browser = firefox
```

### Autostart

Les programmes lances avec `exec-once` ne demarrent qu'a l'ouverture de la session, pas au reload de la config.

```ini
exec-once = waybar
exec-once = mako
exec-once = hyprpaper
exec-once = wl-paste --watch cliphist store
exec-once = /usr/libexec/kf6/polkit-kde-authentication-agent-1
```

> [!info] Polkit
> L'agent polkit gere les popups de mot de passe administrateur. Si KDE Plasma est installe sur la machine, l'agent KDE (`polkit-kde-authentication-agent-1`) est deja present. Sinon, installer `polkit-gnome` et lancer `/usr/libexec/polkit-gnome-authentication-agent-1`.

### Animations

Les courbes bezier definissent le profil d'acceleration des animations. `overshot` donne un leger rebond a l'arrivee, `smoothOut` une sortie rapide.

```ini
animations {
    enabled = yes, please :)

    bezier = smoothOut, 0.36, 0, 0.66, -0.56
    bezier = smoothIn, 0.25, 1, 0.5, 1
    bezier = overshot, 0.05, 0.9, 0.1, 1.1
    bezier = linear, 0, 0, 1, 1

    # Fenetres : slide avec rebond
    animation = windows, 1, 4, overshot, slide
    animation = windowsIn, 1, 4, overshot, slide
    animation = windowsOut, 1, 3, smoothOut, slide
    animation = windowsMove, 1, 3, overshot

    # Bordure animee qui tourne en boucle
    animation = border, 1, 10, default
    animation = borderangle, 1, 50, linear, loop

    # Fondu
    animation = fade, 1, 3, smoothIn
    animation = fadeIn, 1, 3, smoothIn
    animation = fadeOut, 1, 3, smoothOut

    # Layers (waybar, wofi, etc.)
    animation = layers, 1, 3, overshot
    animation = layersIn, 1, 3, overshot, fade
    animation = layersOut, 1, 2, smoothOut, fade
    animation = fadeLayersIn, 1, 3, smoothIn
    animation = fadeLayersOut, 1, 3, smoothOut

    # Changement de workspace : slide avec rebond
    animation = workspaces, 1, 4, overshot, slide
    animation = workspacesIn, 1, 4, overshot, slide
    animation = workspacesOut, 1, 3, smoothOut, slide
}
```

### Workspaces par ecran

Les workspaces peuvent etre attribues a un ecran specifique. Pratique pour toujours avoir ses outils de travail sur l'ultrawide et le monitoring sur le laptop.

```ini
# Workspaces 1-5 sur l'ultrawide
workspace = 1, monitor:DP-5, default:true
workspace = 2, monitor:DP-5
workspace = 3, monitor:DP-5
workspace = 4, monitor:DP-5
workspace = 5, monitor:DP-5

# Workspaces 6-9 sur le laptop
workspace = 6, monitor:eDP-1, default:true
workspace = 7, monitor:eDP-1
workspace = 8, monitor:eDP-1
workspace = 9, monitor:eDP-1
```

## Raccourcis clavier

La touche `SUPER` correspond a la touche Windows du clavier.

### Lancer et fermer

| Raccourci | Action |
|---|---|
| `SUPER + Q` | Ouvrir un nouveau terminal |
| `SUPER + D` | Lanceur d'applications (wofi) |
| `SUPER + E` | Gestionnaire de fichiers |
| `SUPER + C` | Fermer la fenetre active |
| `SUPER + M` | Quitter Hyprland (ferme la session) |
| `SUPER + L` | Verrouiller l'ecran |

### Gestion des fenetres

| Raccourci | Action |
|---|---|
| `SUPER + F` | Basculer en plein ecran |
| `SUPER + V` | Basculer en mode flottant (la fenetre sort du tiling) |
| `SUPER + P` | Pseudo-tiling (la fenetre garde sa taille dans le tiling) |
| `SUPER + J` | Alterner split horizontal/vertical |

### Naviguer entre les fenetres

| Raccourci | Action |
|---|---|
| `SUPER + gauche` | Focus sur la fenetre a gauche |
| `SUPER + droite` | Focus sur la fenetre a droite |
| `SUPER + haut` | Focus sur la fenetre du haut |
| `SUPER + bas` | Focus sur la fenetre du bas |

### Deplacer les fenetres

| Raccourci | Action |
|---|---|
| `SUPER + SHIFT + gauche` | Deplacer la fenetre vers la gauche |
| `SUPER + SHIFT + droite` | Deplacer la fenetre vers la droite |
| `SUPER + SHIFT + haut` | Deplacer la fenetre vers le haut |
| `SUPER + SHIFT + bas` | Deplacer la fenetre vers le bas |
| `SUPER + clic gauche` | Deplacer la fenetre a la souris (drag) |

> [!info] Deplacement entre ecrans
> Si la fenetre est au bord d'un ecran et qu'on la deplace dans cette direction, elle passe sur l'ecran adjacent. Par exemple `SUPER + SHIFT + haut` sur le laptop enverra la fenetre vers l'ultrawide au dessus.

### Redimensionner les fenetres

| Raccourci | Action |
|---|---|
| `SUPER + CTRL + gauche` | Reduire la largeur (-40px) |
| `SUPER + CTRL + droite` | Augmenter la largeur (+40px) |
| `SUPER + CTRL + haut` | Reduire la hauteur (-40px) |
| `SUPER + CTRL + bas` | Augmenter la hauteur (+40px) |
| `SUPER + clic droit` | Redimensionner a la souris (drag) |
| Bords de fenetre | Cliquer-glisser sur le bord pour redimensionner (active via `resize_on_border`) |

### Workspaces

| Raccourci | Action |
|---|---|
| `SUPER + 1` a `SUPER + 9` | Aller au workspace 1 a 9 |
| `SUPER + 0` | Aller au workspace 10 |
| `SUPER + SHIFT + 1` a `SUPER + SHIFT + 9` | Envoyer la fenetre active vers le workspace 1 a 9 |
| `SUPER + SHIFT + 0` | Envoyer la fenetre vers le workspace 10 |
| `SUPER + molette haut` | Workspace precedent |
| `SUPER + molette bas` | Workspace suivant |
| `SUPER + S` | Afficher/masquer le scratchpad |
| `SUPER + SHIFT + S` | Envoyer la fenetre dans le scratchpad |
| Swipe 3 doigts horizontalement | Changer de workspace (touchpad) |

> [!info] Workspaces et ecrans
> Les workspaces 1 a 5 sont attaches a l'ultrawide, les workspaces 6 a 9 au laptop. Quand on fait `SUPER + 1`, le focus va automatiquement sur l'ultrawide. `SUPER + 6` ramene le focus sur le laptop. Envoyer une fenetre vers un workspace d'un autre ecran la deplace physiquement vers cet ecran.

### Screenshots

| Raccourci | Action |
|---|---|
| `Impr. ecran` | Selectionner une zone, copier dans le presse-papiers |
| `SHIFT + Impr. ecran` | Capturer l'ecran entier dans le presse-papiers |
| `SUPER + Impr. ecran` | Selectionner une zone, sauvegarder en PNG dans `~/Images/` |

### Clipboard

| Raccourci | Action |
|---|---|
| `SUPER + SHIFT + V` | Afficher l'historique du presse-papiers (wofi) |

### Media

| Raccourci | Action |
|---|---|
| `Volume +` | Augmenter le volume de 5% |
| `Volume -` | Baisser le volume de 5% |
| `Mute` | Couper/reactiver le son |
| `Mute micro` | Couper/reactiver le micro |
| `Luminosite +` | Augmenter la luminosite de 5% |
| `Luminosite -` | Baisser la luminosite de 5% |
| `Play/Pause` | Lecture/pause du media en cours |
| `Suivant` | Piste suivante |
| `Precedent` | Piste precedente |

### Commandes hyprctl equivalentes

Tous les raccourcis clavier appellent des dispatchers Hyprland. On peut les executer manuellement avec `hyprctl dispatch` :

```bash
# Ouvrir un terminal
hyprctl dispatch exec ghostty

# Fermer la fenetre active
hyprctl dispatch killactive

# Passer en plein ecran
hyprctl dispatch fullscreen 0

# Basculer en flottant
hyprctl dispatch togglefloating

# Deplacer le focus
hyprctl dispatch movefocus l    # gauche
hyprctl dispatch movefocus r    # droite
hyprctl dispatch movefocus u    # haut
hyprctl dispatch movefocus d    # bas

# Deplacer la fenetre
hyprctl dispatch movewindow l
hyprctl dispatch movewindow r
hyprctl dispatch movewindow u
hyprctl dispatch movewindow d

# Redimensionner la fenetre
hyprctl dispatch resizeactive 100 0     # +100px en largeur
hyprctl dispatch resizeactive -100 0    # -100px en largeur
hyprctl dispatch resizeactive 0 100     # +100px en hauteur
hyprctl dispatch resizeactive 0 -100    # -100px en hauteur

# Changer de workspace
hyprctl dispatch workspace 3

# Envoyer la fenetre vers un workspace
hyprctl dispatch movetoworkspace 5

# Envoyer la fenetre vers un ecran specifique
hyprctl dispatch movewindow mon:DP-5
hyprctl dispatch movewindow mon:eDP-1
```

## Configuration de Waybar

Waybar est la barre de statut. Deux fichiers dans `~/.config/waybar/` :

### config.jsonc

Definit les modules et leur position :

```jsonc
{
    "layer": "top",
    "position": "top",
    "height": 34,
    "spacing": 8,

    "modules-left": ["hyprland/workspaces", "hyprland/window"],
    "modules-center": ["clock"],
    "modules-right": [
        "mpris", "tray", "cpu", "memory", "temperature",
        "pulseaudio", "network", "battery", "custom/power"
    ],

    "hyprland/workspaces": {
        "format": "{id}",
        "on-click": "activate",
        "sort-by-number": true
    },

    "clock": {
        "format": "{:%H:%M  %a %d %b}",
        "tooltip-format": "<tt>{calendar}</tt>"
    },

    "cpu": {
        "interval": 5,
        "format": "󰍛 {usage}%"
    },

    "memory": {
        "interval": 10,
        "format": "󰘚 {percentage}%",
        "tooltip-format": "{used:0.1f} / {total:0.1f} Go"
    },

    "temperature": {
        "interval": 5,
        "critical-threshold": 80,
        "format": " {temperatureC}°C"
    },

    "mpris": {
        "format": "{player_icon} {artist} - {title}",
        "max-length": 40
    },

    "battery": {
        "format": "{icon} {capacity}%",
        "format-charging": "󰂄 {capacity}%",
        "states": { "warning": 30, "critical": 15 }
    },

    "network": {
        "format-wifi": "󰤨 {essid}",
        "format-ethernet": "󰈀 Filaire",
        "format-disconnected": "󰤭 Deconnecte"
    },

    "pulseaudio": {
        "format": "{icon} {volume}%",
        "format-muted": "󰝟 muet",
        "on-click": "wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle"
    }
}
```

### style.css

Theme Catppuccin Mocha avec fond semi-transparent. Chaque module systeme a sa couleur : CPU en cyan, RAM en violet, temperature en vert (rouge si critique), media en rose.

Le fichier complet est dans `~/.config/waybar/style.css`.

## Clipboard manager (cliphist)

cliphist stocke l'historique du presse-papiers. Le daemon tourne au demarrage via :

```ini
exec-once = wl-paste --watch cliphist store
```

Consulter l'historique avec `SUPER + SHIFT + V` qui ouvre wofi en mode dmenu.

Gestion manuelle :

```bash
# Lister l'historique
cliphist list

# Vider l'historique
cliphist wipe
```

## Theme GTK

Pour que les applications GTK respectent le theme sombre :

```bash
# Appliquer le theme sombre
gsettings set org.gnome.desktop.interface gtk-theme "Breeze-Dark"
gsettings set org.gnome.desktop.interface color-scheme "prefer-dark"
gsettings set org.gnome.desktop.interface icon-theme "breeze-dark"
gsettings set org.gnome.desktop.interface cursor-theme "breeze_cursors"
gsettings set org.gnome.desktop.interface cursor-size 24
```

Les variables d'environnement dans `hyprland.conf` assurent que le theme est aussi applique aux applications lancees depuis Hyprland.

## Commandes utiles

### Hyprctl

`hyprctl` permet d'interagir avec Hyprland en temps reel :

```bash
# Voir les moniteurs connectes
hyprctl monitors

# Voir les fenetres ouvertes
hyprctl clients

# Recharger la config (sans redemarrer la session)
hyprctl reload

# Voir les workspaces actifs
hyprctl workspaces

# Dispatcher une action
hyprctl dispatch exec ghostty
```

### Debug

```bash
# Logs Hyprland
cat /tmp/hypr/$HYPRLAND_INSTANCE_SIGNATURE/hyprland.log

# Tester une notification
notify-send "Test" "Ceci est un test"

# Verifier la config waybar
waybar -l debug
```
